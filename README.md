# Guess The Number - a Python Number Challenge game
# Project Overview
Guess The Number is a phyton based number guessing game.
It allows the player to pick a diffciculty level according to their wish.
The main aim of the game is that the player must guess the secret number as generated by the computer.

# Features
- Game Ttitle
- Rules
- Nmae of player
- Types od difficulty

    -> Medium Lvel
    -> Hard Level
- Ranadom Number generation
- Limited number of attempts
- Higher/Lower hints
- Score Calculation
- ScoreBoard
- Input validation
- Error handling
- Unit testing

# Technologies Used in the Game

- Random module for picking the number
- OS module 
- Unittest module
